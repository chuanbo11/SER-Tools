# SER Tools

Windows 系统优化工具集。绿色免安装，解压即用，不写注册表。

## 两个版本

| 版本 | 适用系统 | 说明 |
| --- | --- | --- |
| Win11 版 | Windows 10 1809 / 11 | WinUI 3 界面，Fluent 设计，自包含运行时 |
| 通用版 | Windows 7 SP1 ~ 11 | 经典界面，体积更小，启动更快 |

## 功能

软件卸载 · 内存优化 · C 盘清理 · 空间侦探 · 磁盘分析 · 开机启动项 · 系统瘦身 · UWP 移除 · 开机耗时 · 网络优化 · 启动影响评估 · 进程管家 · 隐私痕迹清理

原生 Windows 应用，无需安装 .NET 运行时。
